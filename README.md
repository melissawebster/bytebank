Tech Challenge nº 1 for Front End Engineering POS TECH at FIAP.
================================================================
💳 ByteBank is a fictional digital banking application created for portfolio purposes and also as part of my postgraduate work.
It showcases modern front-end development with Next.js, React, TailwindCSS, and other technologies.

👉 Live demo: https://bytebank-pied.vercel.app

🌟 Project Purpose
- Demonstrate responsive and interactive UI
- Apply modern front-end development concepts
- Create a realistic fictional banking experience for portfolio and academic purposes

🛠️ Technologies Used
- Next.js 15
- Tailwind CSS
- React Hook Form + Zod
- Jest + Testing Library
- API Router
- ESLint

✨ Features
- Fully responsive landing page (desktop & mobile)
- Modal dialogs for Sign Up and Login
- UI built with Tailwind CSS and reusable components
- SEO configured with Next.js Metadata API

📌 Notes
- This is a fictional project; no real banking integration exists.
- Developed for portfolio purposes and as a postgraduate project.
